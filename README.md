# MakeCode micro:bit SVG Exporter

If you want to read japanese version, README_ja is [here](/README_ja.md)!

A Chrome extension that exports MakeCode micro:bit program blocks as standalone SVG files without sticky-note labels.

No server communication, cloud services, or external conversion software are required.
The extension UI is available in Japanese and English and follows the browser language.

## Usage

0. download extension [here](https://github.com/unicha71/makecode-svg/releases) and extract somewhere.
1. Open `chrome://extensions` in Google Chrome.
2. Enable **Developer mode**.
3. Click **Load unpacked** and select the `svg_only` folder.
4. Open MakeCode micro:bit: https://makecode.microbit.org/
5. Display your program blocks.
6. Click **Save as SVG** from the extension popup.

You can also right-click anywhere on the MakeCode page and choose **Export as SVG**.

## Notes

SVG files generated by this extension may not be displayed correctly in Microsoft Word.

This is due to limitations in Word's SVG rendering engine. If you want to insert MakeCode vector graphics into Word documents, you will usually need to convert the SVG file to EMF format using software such as Inkscape.
